## Publish free (GitHub Pages)
1. Create a GitHub repository; upload ALL files/folders (keep `assets/` and `images/`).
2. Settings → Pages → Deploy from a branch → `main` / root.

## Own domain
1. Buy a domain. 2. Settings → Pages → Custom domain → save (before touching DNS).
3. At your registrar add A records for `@`: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153; and a CNAME for `www` → `<username>.github.io`.
4. After DNS updates, tick "Enforce HTTPS".
